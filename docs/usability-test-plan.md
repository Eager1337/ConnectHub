# ConnectHub — Usability Test Plan

## Purpose
Evaluate whether students can understand the navigation and complete common campus-community tasks using the ConnectHub front-end prototype.

## Participants
Target 5–8 university students, recruited voluntarily through convenience sampling. Record only participant codes and relevant broad context; avoid unnecessary personal data.

## Materials
- Laptop or mobile device with a modern browser
- ConnectHub prototype
- Task sheet
- Observation and note-taking sheet
- Consent statement

## Procedure
1. Explain the purpose and that this is a prototype, not a live service.
2. Obtain informed consent.
3. Ask participants to think aloud while attempting each task.
4. Avoid coaching; if a participant is stuck, note the difficulty before offering help.
5. Ask brief post-task questions about clarity and confidence.
6. Thank the participant and store anonymised notes securely.

## Tasks
| ID | Task | Completion evidence |
|---|---|---|
| T1 | Find the design thinking workshop details | Correct date, time and location identified |
| T2 | Save a useful feed post | Post appears in Saved posts |
| T3 | Publish a short update | New post appears in Home feed |
| T4 | Find a study-related group | Correct group identified on Discover |
| T5 | RSVP to Campus culture day | Button changes to Going |
| T6 | Mark notifications as read | Unread styling is removed |

## Measures
- Task completion: completed / attempted
- Time on task (optional)
- Errors, wrong turns and requests for help
- Participant comments and confidence rating (1–5)
- Severity and frequency of observed usability issues

## Post-test questions
1. Which part of the interface was easiest to understand?
2. Was any label or action confusing?
3. Could you tell when an action had been completed?
4. What information would you expect to see but could not find?
5. What one change would most improve this interface?

## Analysis and reporting
Calculate task completion percentages descriptively. Group observations into recurring themes and prioritise issues by impact and frequency. Include actual participant counts and anonymised examples in the final report. A small convenience sample is formative and should not be presented as statistically representative.
